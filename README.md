# Social Scheduler

This repository contains the frontend application for a social media scheduling dashboard built with React, Vite, TypeScript, and Tailwind CSS.

## Project Scope

This project is ONLY for the frontend. It does not include any backend, server, database, authentication service, or API layer.

There is no backend code in this repository, and no server-side logic is implemented here. Any data handling, scheduling logic, or API integrations would need to be provided by a separate backend service outside this project.

## Features

- Social media content planning interface
- Platform channel selection
- AI-assisted content composer workflow
- Modern responsive frontend UI
- React-based client application

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router

## Getting Started

```bash
cd client
npm install
npm run dev
```

Then open the local Vite development URL in your browser.

## Available Routes

This frontend app includes the following routes for navigation:

- `/` - Home page
- `/login` - Login page
- `/dashboard` - Dashboard overview
- `/accounts` - Connected social accounts page
- `/schedule` - Scheduler page
- `/ai-composer` - AI content composer page

You can navigate to these pages directly in the browser using the route paths above, or through the app navigation UI once the frontend is running.

## Important Note

This repository is intentionally frontend-only. The backend and all server-side functionality are not included here.
